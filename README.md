# shave-it
virtual shaving program in cpp and open gl
.exe file in /Shave-IT/

contols:
m           :   mirror shave
0-9         :   set shave level
+/-         :   additional shaving precision
mousewheel  :   shave radius
b           :   grow beard
h           :   grow hair

space to activate/deactivate camera controls:
wasd : movement
mouselook
